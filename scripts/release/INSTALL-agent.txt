PC Club Management System {VERSION} - agent for the club PCs (Windows 10/11, win-x64)
=====================================================================================

The agent is the Windows service "ClubAgent" on every gaming PC. It registers the PC with the
club server, sends heartbeats and runs the commands from the admin UI. The lock screen is in the
launcher package (ccms-launcher-{VERSION}-win-x64.zip). No .NET installation is needed.

Install (on every gaming PC, as Administrator)
1. Check the files: compare the SHA-256 of both zips with SHA256SUMS of the release
   (PowerShell: Get-FileHash .\ccms-agent-{VERSION}-win-x64.zip).
2. Extract this zip AND the launcher zip into the same folder. The folder then has agent\,
   launcher\, install-client.ps1 and Install.cmd.
3. Run as Administrator:
     Install.cmd -ServerUrl "http://<server-or-router>:5081" -EnrollmentToken "<token>" -KioskMode
   The enrollment token is printed by the server installer (Docker: CMS_ENROLLMENT_TOKEN).
   Without the token the PC waits for approval in the admin UI (Devices).
   -KioskMode makes the lock screen the shell of the player account ClubUser (only of this account:
   ClubAdmin and the other administrators keep explorer.exe and Task Manager).
4. Check: Get-Service ClubAgent shows Running; the PC is online in the admin UI. The PC is locked
   until a session starts or staff unlock it.

Kiosk password: the password of ClubUser is random (32 characters) and new on every run of the
installer. Nobody sees it: the installer never prints it and never writes it to a file. Windows keeps
it for the automatic sign-in as an LSA secret, not in the registry. To reset it, run Install.cmd again
with the same options.

Recovery account ClubAdmin: when it does not exist, the installer asks for its password. A run without
a console (as SYSTEM: RMM tools, Intune) asks nothing and creates no ClubAdmin; give the password from
PowerShell instead:
  .\install-client.ps1 -ServerUrl "http://<server>:5081" -EnrollmentToken "<token>" -KioskMode -AdminPassword (Read-Host -AsSecureString)

Update: extract the new zips into a new folder and run Install.cmd again with the same options. Do it
when no session runs on the PC. The installer first copies the new files to C:\ClubAgent.new and
C:\ClubLauncher.new and backs up the old ones (C:\ClubAgent.old, C:\ClubLauncher.old); a failure there
changes nothing. Then it stops the agent and the lock screen, copies the files and starts the agent.
If the copy or the start fails, it restores the old version, starts it again and ends with exit code 1
("UPDATE FAILED ... The old version is restored and runs again"). On success it signs out ClubUser; the
automatic sign-in starts the new lock screen ("RESULT: OK"). No restart of the PC is needed.
The agent log is C:\ProgramData\ClubAgent\logs\agent.log (Administrators only).
Remove the kiosk shell: uninstall-kiosk.ps1. Guide: docs/ClubDeployment.md in the source repository.

Українською: розпакуйте цей архів і архів launcher в одну папку та запустіть від імені адміністратора
Install.cmd -ServerUrl "http://<сервер>:5081" -EnrollmentToken "<токен>" -KioskMode.
Пароль облікового запису ClubUser випадковий і новий після кожного запуску інсталятора; щоб скинути
його, запустіть Install.cmd ще раз з тими самими параметрами.
Оновлення: запустіть Install.cmd нової версії з тими самими параметрами, коли на ПК немає сесії. Якщо
копіювання або запуск не вдалися, інсталятор повертає стару версію і завершується з кодом 1.
